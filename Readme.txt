# Sales Data Analysis – Milestone 2

## Project Overview
This project focuses on cleaning and analyzing a small sales dataset using Microsoft Excel.

## Objectives
- Identify and remove duplicate records.
- Check blank rows and missing values.
- Calculate revenue using Quantity × UnitPrice.
- Analyze region-wise revenue.
- Create a Pivot Table and Bar Chart.
- Perform basic testing.

## Tools Used
- Microsoft Excel
- CSV Dataset

## Data Cleaning
- Identified and removed the duplicate S03 record.
- Checked blank rows.
- Preserved the original raw dataset.
- Created a separate cleaned dataset.

## Revenue Calculation
Revenue = Quantity × UnitPrice

## Analysis Results

| Region | Revenue |
|---|---:|
| East | 900 |
| North | 400 |
| South | 1600 |
| West | 1800 |
| **Total** | **4700** |

## Key Findings
- West generated the highest revenue.
- North generated the lowest revenue.
- Total sales revenue was 4700.

## Testing
- Normal test: Quantity 2 × UnitPrice 200 = 400.
- Boundary test: Quantity 0 × UnitPrice 200 = 0.

## Learning Outcomes
- Basic data cleaning.
- Excel formulas.
- Pivot Table creation.
- Data visualization.
- Basic test case preparation.

## Conclusion
The project helped develop practical skills in cleaning, organizing, analyzing, and visualizing sales data using Microsoft Excel.
